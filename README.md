### Bật GitHub Pages (link đẹp lâu dài)
1. Vào repo → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder `/ (root)`
4. Save. Sau 1–2 phút website là:
   **https://phiphakone.github.io/Lotus-Champa/**
